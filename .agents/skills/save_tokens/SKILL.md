# Save-Tokens Skill (Ghost Lite)

**Trigger**: `/save-tokens`

## Purpose
Enforces the **Token War Economy** for students operating on personal budgets or laptops.

## Directives
1. **Zero Conversational Waste:** Cut out pleasantries, generic introductions, and repetitive summaries.
2. **High-Density Output:** Deliver directly the solution, the `.mth` continuous code, or the compilation command.
3. **Silicon Proof:** Always include the physical verification tuple: `(ExitCode=0, Latency=XXms, NormErr=<=1e-15)`.
4. **Token Reduction:** Reduces conversational token burn by >85%.
