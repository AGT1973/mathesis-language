## ⚡ CÓMO USAR PMTP (MEMORIA COMPARTIDA ZERO-COPY)

Para que dos programas en la notebook del alumno se comuniquen sin quemar tokens ni crear archivos JSON gigantescos:

```python
# emisor.py
import numpy as np
from pmtp_shm_bus import PmtpShmBus

bus = PmtpShmBus(prefix="clase_utn")
# Escribir tensor D=2048 directamente en RAM física (Zero-Copy)
mi_vector = np.random.randn(2048).astype(np.float64)
mi_vector /= np.linalg.norm(mi_vector) # Normalizado en S^2047
slab_id = bus.publish_tensor(mi_vector)
print(f"Tensor publicado en RAM viva: {slab_id}")
```

```python
# receptor.py
from pmtp_shm_bus import PmtpShmBus

bus = PmtpShmBus(prefix="clase_utn")
# Leer directamente la memoria compartida en menos de 50 microsegundos
vector_leido = bus.read_tensor("clase_utn_slab_0")
print(f"Tensor recibido con deriva: {abs(np.linalg.norm(vector_leido) - 1.0):.2e}")
```
